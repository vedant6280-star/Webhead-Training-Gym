
# 🕷️ Webhead Training – Phase 1

**Build your foundation. Train smart. Become stronger.**

Webhead Training is a Spider-Man-inspired beginner gym planner designed to help users develop consistency, improve stamina, and build basic strength through an 8-week training program.

## 🔥 Features

- 8-week beginner training roadmap
- 4 scheduled training days per week
- Full-body machine workouts
- Cardio and recovery days
- Weekly workout checklist
- Progress tracking dashboard
- Automatic progress saving in the browser
- Export workout progress as JSON
- Mobile-friendly interface
- Dark red and blue Spider-Man-inspired theme

## 💪 Training Schedule

| Day | Workout |
|---|---|
| Monday | Full Body A |
| Tuesday | Cardio |
| Wednesday | Recovery |
| Thursday | Full Body B |
| Friday | Rest |
| Saturday | Full Body C |
| Sunday | Recovery |

## 📅 Training Roadmap

- Weeks 1–2: Learn the machines and techniques.
- Weeks 3–4: Build consistency.
- Weeks 5–6: Gradually improve stamina.
- Weeks 7–8: Review progress and technique.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 How to Use

1. Open the website.
2. Select your training week.
3. Follow the scheduled workouts.
4. Mark completed training days.
5. Track your progress.
6. Export your progress when needed.
